# T006 家庭成员图库加载性能优化（双规格缩略图、视口骨架占位与流式无限加载）

## 1. 背景与目标

家庭成员展示空间（图库与相册）在包含数十至上百张照片时，点开主页或相册会出现严重的白屏等待与滚动掉帧卡顿。核心症结如下：

1. **尺寸倒挂（列表加载 2048px 超高清图）**：移动端双列瀑布流单列宽度仅约 180px，但当前直接下载并解码 2048px 原图。100 张照片传输量高达 30MB ~ 60MB，手机 GPU 和解码内存瞬间被打满；
2. **缺乏图片宽高比预设，击穿浏览器懒加载**：瀑布流中的 `<img>` 标签没有预设 `aspectRatio`，未下载前高度全部为 0，导致首屏判定所有照片“在可视区域内”，瞬间触发数十个并发下载；
3. **一次性全量挂载全部 DOM**：页面一口气构建上百个组件节点，拖慢主线程首屏挂载（Hydration）速度。

本任务目标是在**零数据库迁移（Zero DB Migration）**的前提下，全链路实现双规格轻量级缩略图（480px WebP）、预设宽高比骨架占位和流式增量追加渲染，达成**百张照片秒开、滚动 60FPS 丝滑不卡顿**。

## 2. 范围与不做事项

### 本次范围

- **后端双规格缩略图架构（`members` 模块）**：
  - 新增 480px 轻量缩略图文件规范：`members/YYYY/MM/{uuid}_thumb.webp`（质量 78，单张仅 15KB ~ 30KB，相比原图节省 90% 传输量）；
  - 新图上传时同步生成原图与缩略图；存量历史照片在首次请求缩略图时即时自动派生并缓存至磁盘；
  - 媒体读取端点 `/api/v1/media/member-images/{id}` 增加 `?variant=thumb` 查询参数；并配置 `Cache-Control: private, max-age=86400`；
  - 物理删除照片时同步清理伴生的 `_thumb.webp` 文件；
  - 孤立媒体清理工人（`cleanup_orphan_images`）安全兼容识别伴生 `_thumb.webp`，防止被误删；
  - `MemberImageResponse` 增补 `thumbnail_url` 字段。
- **前端瀑布流与相册渲染性能升级**：
  - 瀑布流利用已有 `width`/`height` 强固设置 `aspectRatio` 骨架容器，阻断网络并发击穿；
  - 瀑布流和相册网格优先加载 `thumbnail_url`；
  - 瀑布流实现流式增量追加加载（首屏 24 张，触底哨兵自动无感追加）；
  - 全屏查看器（Lightbox）点击时先以缩略图作为底图模糊过渡，高清原图就绪后淡入。

### 不做事项

- 不引入需要数据库迁移的新增字段（保持表结构稳定，缩略图基于原图存储键规约派生）；
- 近况动态（Post）图片数量较少（最多 9 张），保持现有单规格加载逻辑。

## 3. 验收标准

- [x] `/api/v1/media/member-images/{id}?variant=thumb` 鉴权正常，返回 480px WebP 缩略图（大小约 15KB ~ 30KB），存量历史照片访问时能即时自动生成；
- [x] 物理删除成员照片时，原图与 `_thumb.webp` 伴生文件一同被安全删除；
- [x] 前端瀑布流与相册中图片具备明确的 `aspectRatio` 占位和骨架灰底，页面无布局跳动（CLS = 0），`loading="lazy"` 不会在首屏被击穿；
- [x] 瀑布流初始首屏渲染前 24 张，滚动到底部时自动增量追加，不出现内存暴涨或卡顿；
- [x] 全屏查看器（Lightbox）大图切换顺滑，无白屏黑屏等待；
- [x] 前后端自动化测试、静态检查与生产构建全部 `PASS`。

## 4. 方案与技术影响

| 方案 | 取舍 |
| --- | --- |
| 数据库新增 `thumbnail_storage_key` 字段并执行 Migration | 不选：需要引入新的迁移，老数据回填复杂且有数据孤岛风险 |
| 基于现有 `storage_key` 的规约派生伴生文件 `_thumb.webp` | 采用：无需 Migration，老照片请求缩略图时即时自动生成并落盘，存量与增量照片平滑统一 |
| 瀑布流一次性挂载所有卡片 DOM | 不选：百张照片时 DOM 节点过多，首次水合耗时长 |
| 预置宽高比骨架 + 流式增量加载（首屏 24 张） | 采用：首屏秒开，只下载视口内可见的轻量图，体验与主流商业相册一致 |

- **接口与数据结构**：`MemberImageResponse` 新增 `thumbnail_url: str`（向后兼容）；
- **配置与安全边界**：缩略图严格继承与原图完全一致的鉴权规则，未登录访客访问返回 404，已登录家人方可访问。
