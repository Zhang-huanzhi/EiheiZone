# EiheiZone V1 历史交付

| 产品版本 | `v1.0.0` |
| --- | --- |

本目录保存 V1 从技术栈、需求、设计、任务、测试到部署发布的完整历史材料。它们说明 V1 当时的范围、决策、实现证据和验收结论，不作为 V1.1 之后新功能的需求或设计文档。

## 阅读顺序

1. `00a_v1_technology_stack.md`：最终技术栈和运行基线；
2. `00b_v1_development_process.md`：V1 当时采用的六阶段流程；
3. `01_v1_requirements.md`：V1 需求、范围和验收标准；
4. `02_v1_design.md`：V1 架构、权限、数据、API 和页面设计；
5. `03_v1_plan.md`：V1 任务顺序和完成记录；
6. `04_v1_test_report.md`：V1 测试证据和质量结论；
7. `05_v1_release.md`：V1 部署、分发、运维和风险接受；
8. `06_v1_summary.md`：V1 成果和复盘。

当前开发规则以 [`../../development-process.md`](../../development-process.md)、[`../../architecture.md`](../../architecture.md) 和 [`../../operations.md`](../../operations.md) 为准。

## 历史修正

如果发现会影响 V1 历史理解的事实错误，在 [`ERRATA.md`](ERRATA.md) 中记录原记录、修正内容和对 V1 结论的影响。普通拼写、链接和排版错误可以用文档提交直接修正。
