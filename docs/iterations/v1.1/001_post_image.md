# V1.1：Post 图片展示

| 目标版本 | v1.1.0 |
| --- | --- |
| 状态 | Proposed |
| 分支 | `feat/post-image` |

## 1. 目标

为 Post 增加图片展示能力，使 Owner 发布的近况可以在允许的页面中展示图片。

## 2. 本次范围

- 明确图片来源、数量和生命周期；
- 明确数据库保存图片引用还是独立媒体记录；
- 在 Post 创建、编辑和展示流程中支持确定的图片方案；
- 保持 Public、Family 和 Owner 的原有可见性边界。

## 3. 不做事项

- 尚未决定是否支持多图、裁剪、缩略图和离线缓存；
- 不在本文件中预先指定文件存储、上传方式或最终数据库结构；
- 不改变 V1 历史需求和架构文档。

## 4. 技术方案与候选选择

待实现前记录图片来源、存储、数据库结构、访问授权、类型和大小限制、替换与删除策略，并说明被放弃方案的原因。

## 5. 影响范围

待方案确定后补充数据库、Migration、API、前端页面、权限、部署、备份和安全影响。

## 6. 验收标准

待方案确定后补充旧 Post 兼容性、图片展示、权限边界、异常输入、移动端布局和生产数据迁移验收条件。

## 7. 实现与测试记录

待开发完成后填写代码、Migration、自动化测试和人工验收结果。

## 8. 发布记录

待正式发布后填写合并提交、`v1.1.0` tag、GitHub Release、部署时间和异常情况。

## 9. 遗留风险

待方案和验证完成后填写。
