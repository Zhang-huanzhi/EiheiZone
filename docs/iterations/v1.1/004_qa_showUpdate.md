## 1. 目标与范围

已回答的 QA 在 Family、Owner 问答列表及 Family 首页“最近问答”中显示回答时间，让用户无需进入详情页即可判断回答是否为最新内容。

本次仅增加前端展示：复用 API 已返回的 `answered_at` 字段，不修改后端接口、数据库结构、权限或 QA 状态流转。详情页既有的“回答人 + 回答时间”保持不变；Owner 工作台仅展示待回答问题，不显示回答时间。

## 2. 展示规则

- 已回答且 `answered_at` 有值的记录显示“回答于 {时间}”。
- 未回答记录不显示回答时间、空占位或 `null`。
- 时间继续使用 `zh-CN` 和 `Asia/Shanghai`，格式与现有 QA 详情页一致。
- 列表以问题标题为主信息；状态使用图标和紧凑文字，并在窄屏时移至标题下方，避免挤压标题或逐字换行。
- 提问人、提问时间与回答时间收敛为可换行的辅助信息行，已回答记录不重复显示回答人。
